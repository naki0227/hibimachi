# Game Design — 楽しさを成立させるコアループ

## 原則
**街を見たい → 建物を試してみたい → 暮らしに新しい反応が出た → もう少し育てたい**。現実の行動はこの循環を助けるが、最初のプロトタイプでは抜きでも楽しいことを優先。

## P0: 箱庭単体のループ
1. 既定の初期マップと、1匹の不思議な生き物を受け取る。
2. 建築パレットから木・花・ベンチ・小屋・道・水辺などを選ぶ。
3. 配置プレビューで位置・衝突・設置可否を確認して置く。移動・撤去と取り消しもできる。
4. 生き物が物体との距離・種類・配置条件に反応（ベンチで休憩、木の陰で居眠り、池を見に来る）。
5. 反応を図鑑に1件記録できる（P0は「発見！」程度の軽い演出）。未発見の候補数は見せ過ぎない。
6. プレイヤーが次の配置を試したくなる。

## 配置ルール（初期値、調整可能）
- 16x16論理タイル、地形は草地/道/水辺の3種類。1タイル・2x2タイルのオブジェクトを置ける。
- マップ外、占有済みセル、建築不可の地形への配置は不可。建物のID/位置/向き/レベルは独立データ。
- 配置/移動/撤去は純粋なゲームロジックで検証し、SKSceneは表示だけ。手動保存不要のオートセーブ。
- 配置する度に少なくとも1つの反応可能性が変化することを最初の価値にする。隠し組合せはすべて必須ではない。
- 初期の探索イベントは3件: `bench-rest`（近くのベンチで休む）、`tree-nap`（木の近くで寝る）、`pond-visit`（池を見に来る）。それぞれ起動条件・クールダウン・代替動作を用意。
- 住人AIはP0では状態機械（idle/wander/approach/interact/leave）で十分。生成AIや経路探索の複雑化は不要。

## P1: 生活との接続
- 目標: 1人あたり1〜3個から開始。プリセット（片付け、学習、休息、創作、運動など）または自由入力。
- クエスト: 5〜15分程度で終わる選択式小タスク候補。ルールベースで分割、時間/曜日/取り組みやすさは手動調整できる。押しつけ・完了強制なし。
- 達成: タップで完了、進捗が一部なら小さな達成として記録可。写真/文章は後の機能。
- 報酬: 基本XP + 共通資源（仮名: 「きらめき」）。基本XPは行動ごとに付与する。挑戦/継続ボーナスは上限を設け、得意な行動も評価する。
- 資源: 建築のための共通通貨が全行動で手に入る。行動カテゴリによって必須通貨を分けない。カテゴリ別は装飾上の任意報酬まで。全建物に代替入手経路を設ける。
- クエストが終わると新しい建築案か発見候補をさりげなく示す。煽り通知や連続日数リセット演出なし。

## 初期XPの例（未確定・調整用）
- 1行動チェック: 基本20 XP、建築共通資源5。部分達成は入力した達成割合ではなく、事前登録済みの小タスクごとに付与する。
- ボーナス: 挑戦+0〜10、継続+0〜5、写真・短文記録+0〜5。加点は1イベント上限40 XPなどを候補とし、ユーザーテストで決定。
  - 実装（2026-10-27、ADR-0015）: 記録ボーナスは、クエストに合った記録（まえ・あと／できあがり／量／気分）がそろったとき XP+5・きらめき+2 を1回。どれも写真なしで満たせる。
- AI利用有無や証拠アップロード有無で進行に必要な累積資源量の格差が広がらないよう、日上限/代替獲得手段を比較検証する。
- **不正防止**: 完了イベントはUUID、記録時刻、タスクID、付与ルール版、XP・資源deltaで一意。取り消し/再実行で二重獲得しない。自己申告は証明ではなく自己記録として扱い、罰する仕組みを作らない。

## P2: 街の歴史（アルバム）
- 日付別に目標・クエスト・テキスト・写真と取得した資源・完成した建物を対応付ける。
- 街の建物をタップすると「この家を建てた日」「その日に達成したこと」を本人のみ表示。
- 写真はオプション。アルバムを使わないプレイヤーもゲームが同等に進む。
- 任意の過去記録の編集・削除は可能。消した記録で世界が壊れないよう、XPと履歴の関係は削除方針を事前に設計。

## 長期的な発見・育成
- ペットの好み（花が好き、静かな場所が好きなど）はシンプルな状態として徐々に出現。
- 新しい住人は建築イベントや街の賑わいで招待可能。ただし過度な放置ペナルティは設けない。
- 建築はデコレーションと小さな生活ドラマを増やす方向へ。放置生産・周回効率の最適解競争を主軸にしない。

## 7日間ユーザーテスト
- P0: 日を変えて少なくとも2回戻るか／自発的な再配置があるか／発見を本人が説明できるか。
- P1: チェック記録の負担・楽しかった瞬間・得意/苦手のXP納得感・できない行動による詰みがないか。
- 数値KPIは事前に絶対目標を作らず、初回試験から目標を設ける。
