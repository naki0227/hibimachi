# ADR-0018: 得意・苦手の自己申告と、苦手への小さな XP

- **日付**: 2026-11-02
- **状態**: Accepted（数値はプレイテストで調整）

## 背景
ROADMAP の残り:「得意/苦手の自己申告を任意に扱い、公平性/説明性を検証」。GAME-DESIGN は「得意な行動も評価する」としている。

オーナーの決定（AskUserQuestion、2026-11-02）: 「苦手を少しだけ多めに評価」。

## 決定
1. 目標ごとに「得意・ふつう・苦手」を本人が選ぶ。
   - 初期値は「ふつう」で、いつでも変えられる。
   - 推定や診断はしない（PRIVACY-AI）。
2. 苦手にした目標のクエストは、1回ごとに **XP +2**。
   - きらめき（買い物に使う資源）は増やさない。島づくりの進み方は誰でも同じにするため。
   - 報酬規則は v4。加算した XP は、達成したときの台帳の行に含めて記録する。
     - あとで得意・苦手を変えても、過去の分は書き換えない。
     - 取り消すと、そのとき付いた分だけ戻る。
3. 理由は画面に書く: 「苦手にした目標のクエストは XP が少し多くなります（+2。きらめきは同じ）」。
4. 保存は v8 のまま、目標に省略可の `feeling`（good / hard）を追加する。
   - 知らない値は「ふつう」として読む。

## 選択肢
| 論点 | 採用 | 不採用と理由 |
|---|---|---|
| 苦手の扱い | XP を少し上乗せ（+2） | クエストを短くするだけ: オーナーの選択ではない |
| 上乗せの対象 | XP のみ | きらめきも: 申告しだいで買い物が早くなり、公平さを説明しにくい |
| 得意 | 何も変えない | 得意を減らす: 得意を選ぶ理由がなくなり、正直な申告を妨げる |

## リスク・見直し条件
- 全部を「苦手」にすれば XP が増える。ただし上乗せは1回 +2（標準 20 の 1割）で、きらめきは増えない。乱用が目立てば、苦手にできる目標を1つまでにするなどを検討する。
