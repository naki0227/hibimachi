# ADR-0014: 島が育つ — 20x20の海の中で、レベルか発見で2回広がる

- **日付**: 2026-10-26
- **状態**: Accepted（段階と条件はプレイテストで調整）

## 背景
外部レビュー（2026-10-26、オーナー経由）: 「レベルが上がっても世界に大きな変化が起きない」「初期16×16マップから土地を広げる仕組みなし」。最初の島は 16x16 の地図をほぼ埋めていて、広げる余地がなかった。

## 決定
1. **地図を 20x20 にし、最初の島（16x16の配置）を真ん中に置く**。まわり2マスの海が、広がる余地になる。
2. **広がるのは2回**。条件は解放（ADR-0009）と同じく「レベル **または** 発見数」（Lv3/発見6、Lv5/発見12）。1回ごとに、陸に辺で接する海（いちばん外側の列は除く）を草地にする。
3. **確認する場所**: 起動時、クエスト達成などで進捗が変わったとき、新しい発見があったとき。すでに条件を満たしている既存のプレイヤーは、次の起動で広がる。
4. **広がると元に戻す（undo）の履歴を消す**。古い地形に戻すと新しい土地まで消えるため（成長はごほうびで、編集ではない）。
5. **「島をはじめから」でも、それまでに得た広さは保つ**（得たのはプレイヤーで、島ではない）。
6. **保存は schema v6**（`growthStage`）。v5 以前の 16x16 の保存は、読み込み時に地形・配置物・住人をそろって (+2, +2) ずらして真ん中に移す。移行はストレージ層で行う。
7. カメラは地図全体ではなく「陸のまわり1マス」で合わせる。新しい島の見え方は従来の 16x16 と同じで、広がると少し引いて全体を映す。

## 選択肢
| 論点 | 採用 | 不採用と理由 |
|---|---|---|
| 広げ方 | 最初から大きな地図に海を残す | 実行中に地図サイズを変える: シーンの格子・カメラ・崖の描画を作り直す必要があり、壊れやすい |
| 新しい島 | 従来と同じ大きさから始める | 最初を小さくする: 既存のプレイヤーには変化が見えず、新しい人は窮屈 |

## リスク・見直し条件
- 広がった土地は草地のみ。崖や海辺の描画は既存の地形描画に任せている（実機の見た目で確認する）。
- 3回目以降の成長や、桟橋・小島などの海の遊びは、20x20の余白を使い切るので、地図の拡大と一緒に検討する。
