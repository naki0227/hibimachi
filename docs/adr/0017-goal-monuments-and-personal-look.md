# ADR-0017: 島に育つ目標の塔と、行動・好みで変わる見た目

- **日付**: 2026-11-02
- **状態**: Accepted（見た目の細部は実機で調整）

## 背景
オーナーの構想（2026-10-27）:
- 細分化したものをクリアしていくことで、成長を見えるようにしたい。
- その人の特徴や好みによって、キャラの見た目や島の見た目が変わってもいい。

決定（AskUserQuestion、2026-10-27）:
- 成長は「島に目標の建物が育つ」形で見せる。
- 見た目は「行動の傾向＋本人の好み」で変える。
- AI が性格を診断することはしない（PRIVACY-AI「AIが勝手に人格診断しない」）。

## 決定
1. **目標の塔は、まわりの小島に建てる**。島の周りの海には、もともと飾りの小島が4つある。これを5つに増やし、進めている目標を作った順に割り当てる。
   - 島の配置物とは別物で、場所を取らず、置く操作もいらない。
   - 保存形式も変えない。進み具合から毎回描く。
2. **塔の段階は0〜4**。
   - 0: ステップのない目標は、土台だけ（「ステップに分ける」と育つ）。
   - 1〜3: 終えたステップの割合で上へ伸びる。
   - 4: すべて終えると、屋根と旗がついて完成。

   塔の色は目標のカテゴリで決まる。ステップを1つ終えると、島の画面に「塔が1段のびた」カードを出す。
3. **行動の傾向（島の雰囲気）**: 最近28日の達成をカテゴリごとに数える。
   - 5回以上あって、いちばん多いカテゴリが4割以上なら、そのカテゴリの雰囲気にする。
     - 島の上にときどき小さな光が舞い、色がカテゴリで変わる（学び＝金色、運動＝若草、休息＝水色など）。
     - 設定に「最近は◯◯が多めの島」と出す。
   - 数えているのは回数だけ。性格や良し悪しの判定はしない。
   - 動きを減らす設定のときは出さない。
4. **本人の好み（すきな色）**: 設定で選ぶ。
   - 住人の頭のリボンと、目標の塔の旗の色になる。
   - 初期値は「なし」（今の見た目のまま）。
   - 端末の設定に保存し、ゲームの保存データには入れない。

## 選択肢
| 論点 | 採用 | 不採用と理由 |
|---|---|---|
| 塔の場所 | まわりの小島（自動） | 島の上に配置物として置く: 置き場所・移動・保存形式・図鑑との整合が必要になり、目標の削除とも衝突する |
| 傾向の出し方 | 回数だけの集計と、雰囲気の演出 | AIで特徴を推定: 性格診断につながり、方針に反する |
| 好み | 色を1つ選ぶ | 着せ替えの一式: 絵の量が多く、このPRの規模を超える |

## リスク・見直し条件
- 小島は画面の端にあるため、引いて見ないと塔が見えにくい。気づかれないなら、目標カードから塔へカメラを寄せる操作を足す。
- 雰囲気の閾値（28日・5回・4割）は暫定。
