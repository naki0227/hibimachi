# ADR-0013: 住人とのなかよし度 — なでる・発見で育ち、下がらない

- **日付**: 2026-10-26
- **状態**: Accepted（数値はプレイテストで調整）

## 背景
外部レビュー（2026-10-26、オーナー経由）の最優先は「生き物の個性・愛着・長期的な遊び」。住人の好み（ADR-0009）はあるが、プレイヤーと住人の関係は育たず、住人をタップしても「!」が出るだけだった。

## 決定
1. **住人ごとに `Friendship`（ポイント）を持つ**。なでる（タップ）で+1（1日3回まで数える。それ以上のタップも反応はする）、その住人が新しい発見をすると+2。
2. **段階は はじめまして(0) → なかよし(6) → だいすき(20)**。上がるとカードで知らせる。なかよし以上は、ひまなときにうれしそうにはね、だいすきはハートも見せる。
3. **なかよし度は下がらない**。「できなかった日も島は何も失わない」という約束（GAME-DESIGN）を住人にも当てはめる。毎日なでないと減る仕組みは義務感を生むので採らない。
4. **保存は schema v5**（住人記録に `friendship`）。v1〜v4 は0から始まる。日付が壊れていたら黙って捨てずに読み込みエラーにする（既存の退避の仕組みに乗せる）。
5. **元に戻す（undo）では戻さない**。undo は配置と地形だけ（ADR-0003）。

## リスク・見直し条件
- 1日3回の上限で、なかよしまで最短2日、だいすきまで最短4〜7日。早すぎる・遅すぎるはプレイテストで見る。
- 住人を選んで話しかける・好物をあげるなどの深い交流は、この土台の上で追加を検討する。
