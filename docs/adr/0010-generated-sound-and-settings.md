# ADR-0010: 音はコードで合成し、設定は UserDefaults に置く

- **日付**: 2026-10-26
- **状態**: Accepted（実機での音量バランスと電池への影響は未検証）

## 背景
「音と設定画面」をv1.0の範囲に含めた（ユーザー選択 2026-10-26）。絵はすべてコード描画（ADR-0004）で、外部素材の権利確認を増やしたくない。

## 決定
1. **音は `AVAudioSourceNode` で合成する**（`Synth`: ベル/はじく音の2波形、減衰エンベロープ、同時24音まで、`tanh` で軽く飽和）。音声ファイルを持たない。
2. **効果音8種**（置く・小道・もどす・置けない・クエスト達成・発見・住人到着・タップ）と、**ペンタトニックの静かな音楽**（0.3秒ごとに確率で音を置く。夕方・夜はゆっくり低く）。
3. **オーディオセッションは `ambient`**。消音スイッチに従い、ほかのアプリの音楽を止めない。アプリが背面に回ったらエンジンを止める。
4. **設定は効果音・音楽・ふるえる（触覚）の3つ**。ゲームの記録ではないので保存JSONではなく `UserDefaults.standard` に置く（「島をはじめから」でも消えない）。
5. 設定画面に、最初の案内をもう一度見る・プライバシーポリシー・サポートへのリンク・バージョンを置く。

## 選択肢
| 論点 | 採用 | 不採用と理由 |
|---|---|---|
| 音源 | コードで合成 | 音声ファイル: 素材の権利確認とサイズが増える |
| 再生API | AVAudioEngine + SourceNode | AudioServices の短音: 音楽を鳴らせない / 外部ライブラリ: 依存が増える |
| 設定の保存先 | UserDefaults | 保存JSON: ゲームの状態と混ざり、スキーマ変更が必要 |

## リスク・見直し条件
- 描画スレッドで `OSAllocatedUnfairLock` を取る。音が途切れるなら、ロックなしのリングバッファに替える。
- 音楽の単調さ。プレイテストで「すぐ消した」が多ければ、曲の構成（コード進行・休符）を見直す。
