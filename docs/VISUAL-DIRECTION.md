# Visual Direction — 3案比較と採用方針

## 判断基準
スマホの可読性、建築の操作性、長期アセット制作量、癒やし・好奇心、レトロに偏りすぎない現代感。既存ゲームの画像は**参考用のみ**で、アセットやロゴの転用・トレースは禁止。

## A — Soft Pixel Village（本命）
- 小さな島、明るい草原、手作りの家、丸みある植物、小さな生活者。ほっとする自然光。
- 対象画素密度: 32x32 px タイルを候補。実装ではレンダラの整数倍スケールと端末の実画面で確認。
- パレット: 水色 `#79BDD5`、葉 `#91BFA0`、クリーム `#FAF7EF`、麦 `#F5D99B`、アプリコット `#EDAD94`、文字 `#263747`。
- 良い点: 建物の識別が容易、作る楽しさに集中、毎日開きやすい。
- 弱み: 柔らかいだけでは既存の癒やしゲームに埋もれる。

## B — Mysterious Fairyland Pixel
- 深い森、ランタン、光る植物、川霧、ひっそり生きる不思議な生物。夜間だけの発見。
- パレット: 深水色 `#456F83`、緑 `#5A826B`、金 `#C9B36E`、琥珀 `#D18C56`、紺 `#303C50`。
- 良い点: 探索・発見の期待を作りやすい。生き物の生活演出と相性が良い。
- 弱み: ドット描画・VFX・夜間視認性を作り込むと工数が増える。

## C — Miniature Diorama
- 明快な形とミニマルな島、オモチャのような建築、控えめな陰影。フラット寄り。
- パレット: 空 `#8FDDE0`、草 `#B5D998`、桃 `#F5CBB4`、薄紫 `#D2B5E8`、白 `#F3EEE7`。
- 良い点: 家具と建物の配置が認識しやすい、モダンな操作UIと馴染む。
- 弱み: ピクセルの温かさやファンタジーの個性が弱くなりうる。

## 推奨案 — Aを基盤、Bの発見、CのUI整頓
- **世界**: 柔らかい32px級のピクセルアート、3/4視点の直交グリッドを第一候補（擬似アイソメではない）。最初は読みやすさ・座標の扱いやすさを優先し、描画角度は試作で検証する。
- **季節**: P0は昼だけ。P1以降、夜のランタンや光る花、遠くの音など段階的に追加。
- **生き物**: 2〜3色の明確なシルエットと感情が伝わる4〜6フレーム程度の待機/歩行アニメ。最初は1種だけ。人間の文化を安易にコピーせず独自の生態を設計。
- **建物**: 1〜2タイルで識別できる輪郭。木・石・布の素材差。屋根に1つの色アクセント。複雑なアセットは先送り。
- **UI**: SwiftUIはシステムフォント、ボタン44pt以上、余白を保つ、説明カードの乱用なし。主役は描画エリア。テキストはコントラストを優先。
- **操作**: タップで選択、ドラッグで位置調整、設置プレビューは青/赤に加え形・アイコンで可否表示。ピンチ拡大、二本指パン等の競合は操作実験で確定。
- **動き**: 建築完了は小さなポップ、ペットが近寄る、葉が揺れる。連続パーティクルや画面全体の派手な演出は避ける。
- **音**: 軽い木製クリック、風・水・鳥の環境音（原音源はライセンス確認）。ミュートと触覚フィードバックの切り替え。
- **アクセシビリティ**: 大きな文字、Reduced Motion、色弱配慮、色以外のフィードバック。ゲーム内アイテムへのアクセシブルな代替操作一覧を設ける。

## アセット仕様（初期案）
- 透過PNG、sRGB、アトラス化可能。タイル間のにじみを防ぐ余白・extrusionと nearest filtering を評価。
- スプライトIDはカテゴリ/名称/状態のASCII kebab-case（例: `building-house-small-idle`）。画像本体は後から差し替え可能に。
- 3方向以上のキャラ向きや斜めパースはP0で強制しない。テスト用単色ブロックでゲーム性検証してから制作。
- プレイ画面の情報密度: 下部建築パレット＋画面上端に現在の資源のみ。世界をUIが覆わないこと。
