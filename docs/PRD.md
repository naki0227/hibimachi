# PRD — 生活と連動する箱庭ゲーム

## 1. 狙い
プレイヤーが生活で起こした小さな行動を肯定的に記録し、その結果が「自分で作る世界」の発展と歴史に反映されるiOSゲーム。習慣アプリではなく、**ゲーム自体への愛着**を第一の成功条件とする。

## 2. 想定ユーザー / JTBD
- 生活の小さな達成を続けたいが、既存のストリーク・罰則・数値比較に疲れた人。
- かわいい街や住人を自分で配置・観察したい人。
- 写真・文章で自分の努力を振り返りたい人（後続フェーズ）。
- 身体・生活・家事設備・経済事情が異なり、できる行動が同じではない人。

## 3. コアバリューと非目的
- **価値**: 自由な建築、思いがけない発見、住人/ペットへの愛着、努力が積み重なる視覚的な歴史、AIなしで成立。
- **非目的**: 医療的な生活改善、本人の行動の証明/監視、競争ランキングで煽ること、AIチャットが主画面になること。

## 4. 優先度付き機能
| 優先 | 機能 | 境界 |
|---|---|---|
| P0 | 2Dマップ、自由配置/移動/撤去、2種類以上の配置反応、1ペット、保存復元 | クエスト・AIなしのゲーム性検証 |
| P1 | 目標→小タスク（選択/手編集）、チェック式達成、XP・共通資源付与、建築アンロック | オフライン、決定的ルール |
| P2 | カレンダーと成長アルバム、写真・短文任意記録、建築履歴と紐付け | ローカル保存と削除 |
| P3 | Apple Intelligenceで候補提案/要約・画像観察（対応端末のみ） | AIなしへ常時フォールバック |
| P4 | 箱庭の画像共有、バックアップ/同期、将来Claude API | 明示同意・公開範囲分離 |

## 5. 主要ユーザーフロー
**P0**: アプリ起動 → 小島を眺める → パレットから建物選択 → 配置プレビュー → 決定 → 住人が反応 → 保存 → 次回再開。
**P1**: 目標選択/編集 → 小タスク提案（ルール） → 達成 → XPと共通資源付与 → 建築物購入・配置 → 世界が反応。
**P2**: 任意で写真/文章追加 → 個人アルバムに日付・クエストと共に記録 → その日の建築をタップして思い出を参照。

## 6. 成功条件（仮説・計測計画）
1. P0テストでプレイヤーが外発的報酬なしでも追加配置/探索を自発的に行う。
2. 5名程度の初期テストで配置操作の詰まりが観察でき、反応イベントに気づける。
3. 7日間の使用で少なくとも複数日街を見に戻る利用者がいる（目標数値は実測後設定）。
4. タスク記録は過度な負担にならず、AIなしでも達成→建築まで完走できる。
5. 写真なし/行動制約があっても主要建築物は入手可能。

## 7. 受入条件
- ゲームはオフラインで開き、建築/保存/再開できる。AI/ログイン/位置情報がなくても成立。
- 配置できない場所では理由を示し、資源を消費しない。無効な保存データをクラッシュさせず復旧案内する。
- ペット/住人は飢餓や死亡・ゲームオーバーにならない。連続記録切れによる喪失なし。
- iPhoneで画面回転/アプリ中断/復帰しても建築物が欠損しない（回転対応方針は実機で決定）。
- P1以降のXPが重複付与されない。AIの有無で建築機会が制限されない。
